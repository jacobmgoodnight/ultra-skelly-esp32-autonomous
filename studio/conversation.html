Halloween conversation

A friendly skeleton with 80 reviewed spooky, silly replies. Ask for a ghost joke, say hello, or tell it your first name. Ask for “another joke” to mix Halloween topics. Replies vary before repeating; unfamiliar names are left out. No raw microphone audio is replayed here.

Uses your laptop microphone and the speaker selected in Windows. Keep Skelly’s (Live) Stereo output selected, the ESP32 unplugged including USB, and other control apps disconnected. Start at low volume. The owner confirms one attended Original-voice reply through Skelly with jaw movement. Cleanup, recovery and longer sessions remain unverified.

Connect the speaker before talking

Windows handles Skelly’s Bluetooth audio connection. This page uses the default microphone and output selected in Windows; microphone/speaker choices from the repeat-back tab do not carry over.

If Ultra Skelly v2(Live) Stereo is already connected and selected, and sound actually comes from Skelly, use this page directly. You can skip Enable live audio and repeat-back.

If the Live speaker is missing or unavailable, use the repeat-back lab’s isolated live-audio setup. Keep that page visible until Live-enable write completed appears, then connect the Live speaker in Windows. For first pairing, use Add Bluetooth or other device → Bluetooth; if asked, the documented default PIN is 1234, unless changed. Select Skelly Stereo as Windows output and the laptop microphone as input, then return here. Setup failures are not retried automatically.
