First-time setup · install universal firmware
  1. Use an original ESP32-WROOM. Download universal firmware below and open the .ino in Arduino IDE.
  2. Choose ESP32 Dev Module with Arduino-ESP32 3.3.12, then compile and upload once.
  3. Close Arduino Serial Monitor and other USB tools. Use desktop Chrome or Edge, choose Connect ESP32, then your board’s port (often CP2102 USB to UART Bridge or CH340, with a COM number).
  4. Wait for Ready. Read an existing controller’s settings, or confirm replacement and save your routine or scenes. Later edits use these save buttons.

Prefer a reviewed prebuilt package? The browser installer accepts its local package files. Studio does not compile source in the browser. Keep a copy of your working firmware and settings before reinstalling.

Connection & diagnostics

No Bluetooth MAC address to enter! The ESP32 automatically discovers the address by scanning for this name. Only change it if you renamed your Skelly.

Bluetooth scan retries

Each scan takes up to five seconds. Startup timing includes the scan, so a full missed scan can retry immediately. Faster startup retries end after the first connection or startup period. Later reconnects wait the normal pause after a miss or failure. Motor cooldowns stay unchanged.

Optional local clock schedule · experimental

Set local time through USB tools after every restart. Until then, no routines start. Overnight windows belong to their start day. Existing movement finishes at closing time. No Wi-Fi, automatic DST adjustment or clock retention after power loss.

At 115200 baud, records BLE write results, heap, connection attempts and lighting progress. Boot/reset information and event timestamps are always logged. Lighting test and log instructions ↗

Set up silent mouth clips
  1. Upload a jaw MP3 with the web controller and note its file number.
  2. Save head, arm and torso movement as OFF on every clip (flags 0x00).
  3. Turn the prop’s volume knob to zero for silent movement.

Keep clips at 20–21 seconds. Long open and whisper & gasp each produced ~3-second holds on the test prop. Get the clips and setup guide ↗

Allow independent head + jaw overlap

After a jaw clip, let one due standalone/compound body request take a turn. Cooldowns remain unchanged; jaw-first follow-ups keep their own rules. OFF preserves jaw priority.
