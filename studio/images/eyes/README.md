# Eye preview assets

The 18 unchanged `eye_icon_*.png` images are copied from
[SkellyUltraWebController](https://github.com/martinecker/SkellyUltraWebController/tree/871efa15ff0dda5e41325b19753dffba4a5c35ee/images/skelly)
by Martin Ecker, retrieved October 22, 2026, for the matching numbered expressions.
They are bundled so Studio previews work offline. They are preview artwork only;
the ESP32 sends expression numbers and does not upload these files to the prop.

The upstream repository had no license file at retrieval. This attribution does
not grant additional rights to the artwork or claim it is original project art.
