USB logs and clock

Use desktop Chrome or Edge. Close Arduino Serial Monitor first. Connecting may reset some ESP32 boards. These tools do not connect to Skelly over Bluetooth or confirm physical movement.

Disconnected. No port opens until you choose one.

Optional clock schedules pause after every restart until time is set again. Uses your computer’s local time; set it again after timezone/DST changes. A clock acknowledgment confirms time input, not prop response.

Capture keeps the first 2 MiB; excess bytes are counted and reported. Decoded text may replace invalid UTF-8; use the binary file for corruption diagnosis. Review logs for private information before sharing. Nothing is uploaded.



Install or recover firmware
Custom settings still download as Arduino source. Open it with Arduino IDE/CLI, select ESP32 Dev Module with core 3.3.12, then compile/upload. Close this USB connection before uploading.


Use a fixed head-only package from your reviewed local build or a reviewed release. Maintainer previews are available as head-only-usb-preview Actions artifacts (GitHub sign-in required for artifact downloads); the source/Arduino workflow needs no account. Extract the package and select build.json and head-only.bin together. This installer requires internet and loads ESP Web Tools 10.2.1 only when requested.
