USB logs and clock

Use desktop Chrome or Edge. Close Arduino Serial Monitor first. Connecting may reset some ESP32 boards. These tools do not connect to Skelly over Bluetooth or confirm physical movement.



Disconnected. No port opens until you choose one.


Optional clock schedules pause after every restart until time is set again. Uses your computer’s local time; set it again after timezone/DST changes. A clock acknowledgment confirms time input, not prop response.




Capture keeps the first 2 MiB; excess bytes are counted and reported. Decoded text may replace invalid UTF-8; use the binary file for corruption diagnosis. Review logs for private information before sharing. Nothing is uploaded.




Install or recover firmware
Install the universal firmware once to edit routines and scenes over USB in Send to your ESP32. Its factory routine is Subtle; previously saved USB settings take priority. You can also compile/upload a generated sketch through Arduino IDE/CLI with ESP32 Dev Module and core 3.3.12. Close the USB log connection before uploading.


Use a reviewed universal or fixed head-only package. Actions artifacts are named universal-usb-preview and head-only-usb-preview (GitHub sign-in required); the source/Arduino workflow needs no account. Extract the package and select build.json plus universal.bin or head-only.bin together. The fixed head-only build stays at 2–4 minutes and does not use saved USB settings. This installer requires internet and loads ESP Web Tools 10.2.1 only when requested.




No firmware selected. No USB upload occurs until you explicitly start the installer.
